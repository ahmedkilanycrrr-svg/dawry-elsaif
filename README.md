# دوري الصيف — موقع البطولة

موقع كامل لإدارة دوري صيفي لـ 32 فريق: قرعة، مجموعات، أدوار إقصائية، ولوحة تحكم للمنظم.
البيانات **مشتركة ولحظية بين كل الزوار** — أي حد فاتح الموقع (على أي جهاز) بيشوف أي تحديث (إضافة فريق، نتيجة، قرعة) على طول من غير ما يعمل ريفريش.

## هيكل المشروع
```
tournament-app/
├── index.html              ← الصفحة الرئيسية
├── css/style.css           ← كل التصميم
├── js/app.js                ← منطق الموقع كله
├── js/firebase-config.js    ← بيانات الاتصال بقاعدة البيانات (لازم تملأها بنفسك)
└── README.md
```

## الخطوة 1: اعمل قاعدة بيانات مجانية على Firebase (5 دقايق)

1. روح [console.firebase.google.com](https://console.firebase.google.com) وسجل دخول بحساب جوجل.
2. دوس **Add project** واختار اسم زي `dawry-elsaif` ثم كمل الخطوات (تقدر توقف الـ Analytics، مش لازمة).
3. من القايمة الجانبية جوه المشروع، افتح **Build → Firestore Database**.
4. دوس **Create database** → اختار **Start in test mode** → اختار أي موقع سيرفر قريب (زي `eur3` أو `me-west1`) → **Enable**.
   - "test mode" معناها إن أي حد معاه رابط قاعدة البيانات يقدر يقرا/يكتب فيها لفترة (30 يوم افتراضيًا). كويس للتجربة والاستخدام الودّي، مش الأفضل أمنيًا لو البطولة فيها جوايز مادية كبيرة أو بيانات حساسة.
5. ارجع لصفحة المشروع الرئيسية، دوس أيقونة **</>** (Web app) عشان تضيف تطبيق ويب.
6. سمّيه أي اسم ودوس **Register app**. هيديك كتلة كود فيها كائن اسمه `firebaseConfig` — فيه قيم زي:
```js
const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "dawry-elsaif.firebaseapp.com",
  projectId: "dawry-elsaif",
  storageBucket: "dawry-elsaif.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abcdef"
};
```

## الخطوة 2: حط البيانات دي في المشروع

افتح ملف `js/firebase-config.js` وحط القيم اللي نسختها بدل `"ضع_القيمة_هنا"` في كل سطر. احفظ الملف.

## الخطوة 3: شغّل الموقع

- افتح فولدر `tournament-app` في VS Code.
- نزّل إضافة **Live Server**، دوس يمين على `index.html` واختار **Open with Live Server**.
- الموقع هيفتح ويتصل بقاعدة البيانات على طول. جرب تفتحه في تابين أو جهازين مختلفين — أي حاجة تعملها كأدمن في تاب هتظهر فورًا في التاب التاني.

## كلمة سر المنظم
الافتراضية: `admin2026` — غيّرها من تبويب "لوحة التحكم" بعد تسجيل الدخول (بتتخزن في نفس قاعدة البيانات).

## رفعه أونلاين (رابط تشاركه مع الكل)
لو عايز رابط عام يفتحه أي حد من غير VS Code:
- اسحب فولدر المشروع كله على [netlify.com/drop](https://app.netlify.com/drop) وهياخد رابط فورًا، وهيفضل متصل بنفس قاعدة بيانات Firebase.

## ملاحظة أمان
- **test mode** في Firestore بيفضل شغال 30 يوم بس، وبعدها القاعدة تقفل القراءة/الكتابة تلقائيًا. لو عايز يفضل شغال بعد كده، تقدر تعدل الـ Rules في Firestore يدويًا (Firestore Database → Rules) بحيث تسمح بالقراءة والكتابة بدون تاريخ انتهاء — قولّي لو وصلت للمرحلة دي وأنا أوريك الكود المضبوط.
- كلمة سر المنظم في الموقع ده حماية بسيطة على مستوى الواجهة، مش تشفير حقيقي. مناسبة لدوري ودّي، مش لحاجة فيها بيانات حساسة أو أموال كبيرة.
